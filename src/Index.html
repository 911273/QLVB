Quét & Cập nhật văn bản từ Google Drive

Hệ thống sẽ đọc toàn bộ file trong folder gốc (kể cả folder con), tự động OCR, phân loại và cập nhật vào cơ sở dữ liệu.

Tự động quét định kỳ

Bật để hệ thống tự quét Drive theo lịch, không cần bấm thủ công.

Hàng đợi OCR (xử lý dần, tránh vượt hạn mức Google)

Khi quét, ảnh/PDF được xếp hàng đợi thay vì OCR ngay. Hệ thống OCR từng ít một: mỗi lượt vài văn bản, mỗi PDF vài trang, và giới hạn số trang/ngày để không vượt hạn mức miễn phí của Vision. PDF nhiều trang sẽ được OCR dần qua nhiều lượt.

Thông tin hệ thống

OCR nâng cao (Google Cloud Vision) — chất lượng tiếng Việt cao

OCR tích hợp của Drive nhận dạng tiếng Việt kém. Nhập Google Cloud Vision API key để dùng động cơ OCR chất lượng cao (giữ đúng dấu). Nếu để trống, hệ thống dùng Drive OCR.

Cách lấy API key (bấm để xem)
  1. Vào console.cloud.google.com → tạo project (hoặc chọn project có sẵn).
  2. Bật Cloud Vision API (APIs & Services → Enable APIs → tìm "Cloud Vision API" → Enable). Cần bật Billing cho project (Vision có mức miễn phí 1.000 trang/tháng).
  3. APIs & Services → Credentials → Create credentials → API key → copy dán vào ô trên.
  4. (Khuyến nghị) Hạn chế API key chỉ cho Cloud Vision API để an toàn.

Loại văn bản

Danh sách loại VB dùng để tự động phân loại. Từ khoá cách nhau bởi dấu phẩy.

Đơn vị ban hành

Danh mục đơn vị ban hành theo cấp, dùng để tự động nhận diện. Từ khoá cách nhau bởi dấu phẩy. Khi văn bản nhắc tới nhiều cấp, hệ thống chọn đơn vị ở cấp cụ thể nhất.
